Vibresia comes with a small local server that AI assistants can talk to. Point an agent at it and it can write a vibscape, check that it compiles, look at what it drew and try again — without you copying a line of code back and forth.

Set it up

It works with any assistant that speaks MCP. Pick yours below.

The one thing to know

Vibresia is the server. The command names the app on your Mac, so if you moved it, use where it actually is — usually /Applications/Vibresia.app.

claude mcp add vibresia -- "/Applications/Vibresia.app/Contents/MacOS/Vibresia" --mcp

That's the server. The other clients want the same two things: the path to that binary, and --mcp as its argument.

What the agent can do

List and read

See every vibscape there is, and the full source of yours.

Test

Compile a shader and draw it. The agent gets the picture back, so it can see what it made and judge it.

Create and edit

Write a new vibscape, or change one that already exists. Nothing is saved unless it compiles, so the folder never fills with broken worlds.

Delete

Remove one you don't want any more.

What a vibscape is

One function, returning a colour. The music arrives as uniforms, so a vibscape draws with the track rather than redrawing it every frame.

The shape

vec3 render(vec2 p, float t)
{
    // p is the position on screen, centred on 0,0 and about -0.5 to 0.5
    // vertically. t is time in seconds.
    float d = length(p);
    float ring = smoothstep(0.05, 0.0, abs(d - 0.25));
    vec3 colour = vec3(1.0, 0.3, 0.8) * ring;
    colour += vec3(0.2, 0.9, 1.0) * uTreble;   // sparkles on the highs
    return colour * uActive;                   // fades out in silence
}

What it can use

The music, as numbers: uBass, uMid, uTreble, uLevel, uBeat, uBeatStrength, uBands[96] (the whole spectrum), uBeats (a beat counter), uActive (how much is playing), uTime, uClock. Plus helpers for shapes, colour and noise.

Your agent can ask for the full list — it doesn't have to guess.

Without an agent

Prefer to write it yourself? In the app, View All → + Custom Vibscape takes the same route: paste the code, press Test, and you'll see the picture before you keep it.
